# クッキングアプリ

## ログイン・新規登録

ログイン画面の「新規登録」から、名前・メールアドレス・パスワードを入力します。登録後に一度だけ表示される復旧コードを控えてください。パスワードを忘れた場合は、ログイン画面の「パスワードを忘れた場合」から、登録メールアドレス・復旧コード・新しいパスワードを入力して再設定できます。ログイン状態はタブを閉じるまで保持されます。復旧コードが未発行の既存アカウントは、次回ログイン時にコードが表示されます。控えるまでは画面を離れないでください。

これはSupabaseなどのサーバーを使わないデモです。アカウントと復旧情報は現在のブラウザー内に保存され、別のブラウザーや端末とは共有されません。復旧コードを失くすとパスワードを再設定できません。復旧コード未発行の既存アカウントで、パスワードも忘れた場合はこの画面から復旧できません。パスワードと復旧コードは平文ではなくソルト付きハッシュで保存しますが、ブラウザー内だけの認証は本番サービス向けの安全な認証ではありません。公開サイトや大切な個人情報を扱うアプリには、メールで本人確認するサーバー認証を使用してください。

レシピ・お気に入り・リクエストもブラウザー内の`localStorage`に保存されるため、別の端末には同期されません。
